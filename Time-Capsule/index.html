HOW IT WORKS
  1. 01

    WRITE

    제목과 본문을 씁니다. 봉인하기 전까지는 언제든 고칠 수 있고, 초안은 자동으로 저장됩니다.

  2. 02

    SEAL

    개봉 날짜를 정하면 메모가 구체 안으로 들어가 봉인됩니다. 봉인된 메모는 수정할 수 없습니다.

  3. 03

    WAIT

    개봉일까지 캡슐은 제목, 날짜, 남은 시간만 보여줍니다. 본문은 열리지 않습니다.

  4. 04

    OPEN

    날짜가 지나면 캡슐을 직접 엽니다. 열린 기록은 아카이브에서 언제든 다시 읽을 수 있습니다.

NOTE 모든 기록은 현재 브라우저에만 저장됩니다. 브라우저 데이터를 삭제하거나 다른 기기에서 접속하면 기록을 확인할 수 없습니다. 글 · 사진 · 음성 · 영상은 이 브라우저의 IndexedDB에만 보관되며 외부 서버로 전송되지 않습니다. 봉인은 화면 위의 잠금일 뿐 서버에서 검증하는 보안 잠금이 아니므로, 개발자 도구나 기기 시계를 바꾸면 내용을 볼 수 있습니다.
